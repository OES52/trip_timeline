# 여행 타임라인 v2 (새 화면)

예전 화면(v1: 저장소 루트의 `App_*.html`, `Style_*.html`)을 처음부터 다시 만든 것.
사이트 첫 주소(`/`)를 열면 `/v2/` 로 넘어옴. 데이터는 v1과 같은 `/api` 를 씀.
v1은 홈랩 사이트에서 뺐고, Apps Script 웹앱의 비상 주소로만 남김 (집 서버가 죽었을 때, 저장소 루트 `Extras.js`).

| 주소 | 내용 |
|---|---|
| `/` | `/v2/` 로 넘김. 루트 `sw.js` 는 v1이 루트에 있던 시절 서비스 워커를 걷어냄 (`web/root/`) |
| `/v1/` | `/v2/` 로 넘김. `/v1/sw.js` 는 폰에 남은 v1 서비스 워커를 걷어냄 (`web/root/v1/`) |
| `/v2/` | 새 화면 |

## 돌리기

```
cd web/v2
npm install
npm run dev      # 화면은 내 PC(http://localhost:5173/v2/), 데이터는 실제 서버
npm test         # 시각·일정 로직 테스트
npm run build    # dist/ 로 빌드 (도커 빌드가 이걸 부름)
```

### 시간 미리보기

주소 뒤에 `?now=2026-12-25T12:30`(일본 시각)을 붙이면 그 시각부터 시계가 흘러감. 여행 전에 당일 화면(지금·다음, 탈 곳·내릴 곳 안내, 막차·영업 경고)을 미리 볼 때 씀.
예: `https://japan2026.oesgame.xyz/v2/?now=2026-12-25T12:30#today`. 이 동안 도장·도착·지출 기록과 일정 조정은 막히고, 머리줄 아래 "끝내기"로 빠져나옴.

## 구조

| 폴더 | 내용 |
|---|---|
| `src/lib` | 순수 로직: 시각, 여행 모델(지금·다음, 지연 예측, 하루 요약), 영업시간 경고, 환승 단계, 색. 화면 코드 없음, 테스트 있음 |
| `src/data` | 서버 호출(`api.js`), 폰 저장본(`cache.js`, v1과 같은 저장소), 앱 상태(`store.js`) |
| `src/ui` | 부품: 껍데기(머리줄·탭·시트), 전광판, 타임라인, 지도, 아이콘 |
| `src/screens` | 화면: 오늘, 일정, 장소, 기록(여권·돈) |
| `src/styles` | `tokens.css`(값은 전부 여기) + 부품별 CSS |

## 디자인 규칙: 역 사인

재료 네 가지에 역할을 정해 둠. 새 화면을 만들 때 역할에 안 맞는 재료는 쓰지 않음.

| 재료 | 역할 | 쓰는 곳 |
|---|---|---|
| 사인 (흰 판, 남색 판, 도시색 띠) | 구조와 이동 | 머리줄, 탭, 날짜 표지판, 장소 줄 |
| 전광 (LED) | 지금 이 순간 | 오늘 화면 전광판, 타임라인의 "今" 칩. 그 외엔 안 씀 |
| 종이 (승차권) | 돈과 기록 | 하루 승차권(비용·걷기), 영수증, 돈 요약 |
| 도장 (인주) | 다녀온 것 | 방문한 장소의 점, 여권 도장(여권 종이는 밝은·어두운 화면 모두 같은 색) |

- 색·크기·간격은 `tokens.css` 값만 씀. 화면 CSS에 숫자 색을 직접 적지 않음 (노선·도시·사람 색은 데이터 색이라 `lib/colors.js`)
- 글자 크기 6단(12/14/16/18/24/32), 굵기 2종(400/700, 숫자 글꼴은 500/600), 간격 4/8 격자, 모서리 3종
- 출구 노랑(주 행동) 버튼은 한 화면에 하나
- 누르는 곳은 48px 이상 (한 손, 장갑)
- 시각·금액·번호는 숫자 글꼴(`.num`)
